# Şimdi Her Zaman Geçmiştir Makinesi

## Dünyanın En Ciddi, En Absürt ve En Gereksiz Zaman Yönetim Sistemi

Bu repository, insanlığın en büyük sorununu çözmek için tasarlanmıştır: **Zaman geçiyor ve sen de geçiyorsun.**

### Ne Yapar?

- Şu anki zamanı gösterir.
- Hemen ardından o zamanın geçmişte kaldığını bildirir.
- Varoluşsal kriz üretir.
- Gerçekten çalışır. Deneyin, inanmayacaksınız.

### Nasıl Kullanılır?

```bash
python zaman_makinesi.py
```

Veya sadece:

```bash
python3 zaman_makinesi.py
```

**Uyarı:** Bu programı çalıştırdıktan sonra şimdi zaten geçmiş olacaktır. Geri dönüş yoktur.

### Özellikler

- %100 Türkçe
- Abartılı ciddiyet
- Gereksiz yere yavaş (ama hızlı da değil)
- Patates içermez
- Çay içermez
- Bilimsel olarak kanıtlanmamış ama çok resmi hisseder
